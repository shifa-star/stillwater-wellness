## [1.4.0] - 2026-08-13
### Added
- Six per-action guide pages: Breathe, Move, Rest, Meditate, Visualize, Nourish — each with a photo hero, a short written guide in the site's gentle voice, a Next button that loops through its series, and a link back to the hub.
- index.html is now a hub: header, hero, and six action tiles (two rows of three) linking to each guide.
- Web-optimized photos in images/ (1080x1080 JPEG, quality 80) derived from the original 2048x2048 photos; originals in instagram/ are untouched.
- Footer year (auto-filled) and the foundation line "STILLWATER WELLNESS · ONENESS WELLNESS LIFESTYLES FOUNDATION".
### Changed
- All seven pages now share styles.css (tile grid + page-hero styles added, palette unchanged).
- README updated to describe the hub and the six pages.
